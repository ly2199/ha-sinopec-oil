# Sinopec Oil Price 中石化油价

![HA 版本](https://img.shields.io/badge/Home%20Assistant-2024.8%2B-blue)
![HACS](https://img.shields.io/badge/HACS-Custom-green)
![版本](https://img.shields.io/badge/版本-1.0.5-orange)

一个 [Home Assistant](https://www.home-assistant.io/) 的 [HACS](https://hacs.xyz/) 自定义集成：

- ⛽ **查询实时油价**：数据来自中国石化"今日油价"公开页面 [cx.sinopecsales.com](https://cx.sinopecsales.com/yjkqiantai/core/initCpb)；
- 🗺️ **省份 + 价区两级配置**：支持云南、四川等按"一价区/二价区…"发布价格的省份，也支持北京、广东等全省统一价的省份；
- 🚗 **多车辆管理**：每辆车独立维护名称、初始里程表读数、常用油品，可在集成选项界面添加/编辑/删除，也可通过服务调用管理；
- 📝 **记录加油**：记录加油量、里程表读数、加油时间、油品与备注，支持**批量导入历史加油数据**；
- 💰 **区分加油费用与实际支付**：加油费用为挂牌价合计、实际支付为真实付款，
  **优惠金额 = 加油费用 − 实际支付，由集成自动计算**（实付留空即视为无优惠）；
- 🧮 **智能计算，少填少输**：
  - 只填**加油金额** → 自动按当日油价算出加油量；
  - 只填**加油量** → 自动算出费用；
  - 只填**实际支付** → 反算加油量（该笔无优惠）；
  - 录入**历史日期**的加油记录 → 自动查询中石化历史调价周期（约 11 个月），按**当天的真实油价**计算；
  - 里程表读数由卡片/表单**自动带出上次读数**，无需重复输入；也可以留空（该区间不计入油耗，其他区间照常）；
- 📊 **自动统计**：累计加油量/费用/实际支付/优惠、累计行驶里程、最近与平均油耗（L/100km）、平均油价、每公里油费、最近加油日期。

> ⚠️ 免责声明：本集成仅供个人学习与参考，油价数据以中国石化官方渠道及油站实际价格为准。

## 安装

### 方式一：HACS（推荐）

1. 确保已安装 [HACS](https://hacs.xyz/)；
2. HACS → 右上角 ⋮ → **自定义存储库** → 仓库地址 `https://github.com/ly2199/ha-sinopec-oil`，类别选 **集成**；
3. 在 HACS 中搜索「Sinopec Oil Price 中石化油价」并下载；
4. 重启 Home Assistant。

### 方式二：手动

将 `custom_components/sinopec_oil/` 整个目录复制到 HA 配置目录的 `custom_components/` 下，重启 HA。

## 配置

### 初始配置（添加集成）

1. 设置 → 设备与服务 → **添加集成** → 搜索「中石化油价」；
2. **选择省份**；
3. 若该省按价区发布油价（如云南），会自动出现**价区选择**步骤：每个选项直接列出**官方公布的适用州市**（如"一价区 · 适用于：昆明"）与参考油价（如"92号 8.44 元/L"），按你所在州市对照选择即可；全省统一价的省份自动跳过；
4. （可选）**添加第一辆车**：名称、当前里程表读数、常用油品。全部留空可跳过。

### 集成选项（修改位置 / 管理车辆）

点击集成条目 → **配置**，菜单式管理：

| 菜单 | 功能 |
| --- | --- |
| ⚙️ 油价设置 | 修改省份/价区、油价刷新间隔（分钟） |
| ➕ 添加车辆 | 名称、初始里程表读数、常用油品 |
| ✏️ 编辑车辆 | 修改初始里程、常用油品 |
| 🗑️ 删除车辆 | 删除车辆及全部记录 |
| 🧹 清空记录 | 保留车辆，清空加油记录 |
| 🧾 加油记录管理 | 查看/删除单条加油记录（修改用 edit 服务） |
| ✅ 完成 | 保存并应用 |

## 服务调用

### 记录加油 `sinopec_oil.record_refuel`

`volume`（加油量）、`total_cost`（加油费用）、`actual_payment`（实际支付）
**至少填一项**，其余自动推算：

| 你填了 | 集成自动算出 |
| --- | --- |
| 加油量 + 加油费用 | 单价 = 费用 ÷ 加油量；优惠 0（未填实付时按全额支付） |
| 加油量 + 加油费用 + 实际支付 | **优惠 = 加油费用 − 实际支付** |
| 只填加油量 | 加油费用 = 加油量 × 当日/历史油价，优惠 0 |
| 只填加油费用 | 加油量 = 费用 ÷ 当日/历史油价，优惠 0 |
| 只填实际支付 | 加油费用 = 实际支付，加油量 = 费用 ÷ 当日/历史油价，优惠 0 |

```yaml
# 例 1：今天加油挂牌价 400 元，用券实付 350 元（优惠 50 元自动算出）
service: sinopec_oil.record_refuel
data:
  vehicle: 家里的 white SUV
  odometer: 12345        # 可选，用于计算区间油耗（卡片/填表会自动带出上次读数）
  total_cost: 400
  actual_payment: 350

# 例 2：录入上个月的历史加油（自动匹配当天油价算费用，无优惠）
service: sinopec_oil.record_refuel
data:
  vehicle: 家里的 white SUV
  date: "2026-08-20 18:30:00"
  volume: 42.5           # 自动按 8/20 所在调价周期的油价算费用
  odometer: 11800
```

> **金额口径**：`total_cost`（加油费用）= 挂牌价合计，用于统计平均油价与每公里油费；
> `actual_payment`（实际支付）= 真实付款，留空即视为无优惠；
> **优惠 = 加油费用 − 实际支付**，由服务自动计算并写入记录，无需手工填。
> 实际支付高于加油费用会被拒绝（优惠不能为负）。
> 1.0.5 之前的旧记录只有 `total_cost`（当时即"实际支付"），
> 集成按「加油费用 = 实际支付、优惠 0」处理，历史金额口径与统计完全不变。

> `odometer`（里程表读数）**可留空**：留空的行照常入库，只是相邻区间不参与油耗统计
> （记为「缺口」，不影响其他区间）。若填写，则必须与相邻记录的里程同步递增、
> 单区间不超过 900 km，否则视为时间-里程矛盾并被拒绝入库。

服务响应（`response_variable`）包含：加油量、加油费用、**实际支付、优惠金额**、单价、
**油价来源**（当前价/历史调价周期）、本次区间里程与油耗。

### 批量导入历史加油 `sinopec_oil.import_refuel_records`

```yaml
service: sinopec_oil.import_refuel_records
data:
  vehicle: 家里的 white SUV
  records:
    - {date: "2026-07-05 09:00:00", odometer: 8500, total_cost: 300, actual_payment: 270}
    - {date: "2026-07-20 19:00:00", odometer: 9080, total_cost: 320}
    - {date: "2026-08-03 08:30:00", odometer: 9650, volume: 40.2, total_cost: 330}
```

每条记录同样走智能计算（自动查当日油价），按日期排序后写入，导入完成即生成全部统计。
`actual_payment` 同样可选：填了就算优惠，留空即无优惠。

**有加油量和费用时，当时油价自动得出**：两字段同时填写时单价=费用÷加油量，
响应中 `price_source` 显示为"费用/加油量"，无需手动算。

### 记录维护（查看 / 删除 / 修改）

```yaml
# 1) 查看全部记录（含 index 序号，按日期升序）
service: sinopec_oil.list_refuel_records
data: {vehicle: 家里的 white SUV}
# 响应：{count, records: [{index, date, odometer, volume, total_cost, actual_payment,
#         discount, price, price_source...}], stats}

# 2) 删除一条记录（统计自动重算）
service: sinopec_oil.delete_refuel_record
data: {vehicle: 家里的 white SUV, index: 2}

# 3) 修改一条记录（只填要改的字段，其余智能重算）
#    只改加油量 → 按记录日期油价重算加油费用（原优惠金额保留）
#    只改费用   → 反算加油量（原优惠金额保留）
#    只改实付   → 加油费用不变，优惠 = 费用 − 新实付
#    量费同给   → 单价=费用/加油量，未给实付则视为无优惠
#    改时间     → 按新日期重新匹配历史油价
service: sinopec_oil.edit_refuel_record
data:
  vehicle: 家里的 white SUV
  index: 2
  volume: 41.5      # 只改这一项，费用按该记录日期的油价自动重算，优惠保持原样
```

也可以在 **集成选项 → 🧾 加油记录管理** 中按车浏览并删除单条记录。

### 查询历史油价 `sinopec_oil.get_price_history`

返回当前省份/价区的历史调价周期（约 24 期 ≈ 11 个月），每期含起止日期与各油品价格：

```yaml
service: sinopec_oil.get_price_history
# 响应：{location: "北京", period_count: 24,
#        labels: {"GAS_92": "92号汽油", "GAS_95": "95号汽油", "CHECHAI_0": "0号柴油", ...},
#        periods: [{start: "2026-09-12", end: "2026-09-24", period_id: 146,
#                   prices:  {"GAS_92": 8.29, "GAS_95": 8.83, ...},
#                   changes: {"GAS_92": 0.2,  "GAS_95": 0.22, ...}}, ...]}
# 说明：prices / changes 的 key 是稳定的数据字段名（GAS_92、GAS_95、CHECHAI_0…），
#       中文名称见 labels；changes 带符号（正=上调，负=下调，0=搁浅）。
```

同样数据也挂在 **"油价更新时间"传感器的 `price_history` 属性**中，仪表盘可直接引用。

### 可视化操作：自定义卡片（推荐，一步到位）

**安装卡片（一次性）**：

1. 把发行包里的 `www/sinopec-oil-card.js` 复制到 HA 配置目录的
   `config/www/` 下（可 scp/Samba/文件管理器插件）；
2. 仪表盘 → 右上角 ⋮ → **管理资源** → 添加资源：
   URL `local/sinopec-oil-card.js`，类型 JavaScript 模块；
3. 仪表盘 → 添加卡片 → **手动**：

```yaml
type: custom:sinopec-oil-card
# 可选配置：
# title: 我的油卡
# vehicle: 大白   # 默认车辆（不填则自动记住上次选择）
```

卡片**自动发现**本集成全部实体（按内部角色标记，非实体 ID），
**无需填写任何实体 ID**，换实体 ID 也不受影响。

**四个页签**：

- **⛽ 加油**：选车（里程自动带出当前读数）→ 填加油量或费用任一项
  （都填则单价=费用÷量）→ 提交。**再填「实际支付」则自动算出优惠**
  （优惠 = 加油费用 − 实际支付；留空即无优惠）。卡片内直接显示计算结果：
  加油量/加油费用/实际支付/优惠/单价/计价来源/本次区间里程与油耗。改"加油时间"
  为历史日期 → 自动按该日期的历史油价计价；油品"自动"= 用该车默认油品。
- **📋 历史**：全部加油记录表格（日期/里程/量/加油费用/实际支付/优惠/单价/区间油耗/备注），
  每条可 **删除**、点开 **修改**（量费改动自动重算另一项且保留原优惠；只改实付则费用不变）；
  支持 **批量导入**（粘贴多行
  `日期, 里程, 加油量, 加油费用, 实际支付[, 油品][, 备注]`，
  实付留空即无优惠；旧 6 列写法 `…, 费用, 油品, 备注` 仍兼容，但整批数据不可新旧混用；
  冲突行会被拒绝并逐行说明原因）。
- **📈 油价**：当前各油品价格与本期涨跌（红涨绿跌）+ 调价方向/期号/距下次调价天数
  + 历史调价周期表 + 价格走势条形图。**油品列由当前省份实际发布的油品动态生成**
  （北京有 6 种、云南按价区不同），不写死 92/95。
- **🚗 统计**：当前里程/累计加油费用/累计实际支付/**累计优惠（含优惠率）**/
  平均油耗/平均油价/每公里油费/加油次数 + 数据质量提示。

**油耗计算规则（重要）**：区间油耗由相邻两次加油的里程差算出，
有效区间须满足 **0 < 里程差 ≤ 900 km** 且时间顺序与里程顺序一致。

- **里程可以留空**：该行照常入库，只是相邻区间不参与油耗统计，
  记为「缺口」并在「数据质量」传感器中计数（**不影响其他区间**）；
- 填了里程却与相邻记录**矛盾**（区间里程 ≤ 0，或与紧邻记录单区间 > 900 km）
  的记录会被**直接拒绝入库**并说明原因，历史补录需插在正确的时间位置；
- 其余区间照常计算：例如 10 条记录中有 1 处缺口，
  「最近油耗 / 平均油耗」仍按其余有效区间给出，只是样本变少；
- 数据出现矛盾或缺口时，「数据质量」传感器与卡片顶部会分别列出
  待修正项与缺口数量，修正或补全后统计自动恢复。

**不想装 JS 卡片？** 备选：集成自带「加油填表」设备
（仪表盘 → 添加卡片 → 按实体 → 勾选该设备全部实体，里程自动预填，
点提交按钮录入，结果见通知）；或开发者工具 → 动作 →
`sinopec_oil.record_refuel` 直接填表单。功能等价，体验弱于卡片。

## 实体

### 油价实体（按省份/价区自动生成）

一个位置一台设备（如「中石化今日油价（北京）」「中石化今日油价（云南·二价区）」）：

| 实体 | 单位 | 说明 |
| --- | --- | --- |
| `<油品>` | 元/L | 当日价格（如"92号汽油"）。属性含 `fuel_key`（稳定数据字段名，供自动化取值）、`price_change`、`price_trend`、`period_high/low/avg` |
| `<油品>` 涨跌额 | 元/L | 本期相对上期的涨跌额，**带符号**（正=上调，负=下调，0=搁浅），可画图与长期统计 |
| `<油品>` 24期最高价 / 最低价 / 均价 | 元/L | 近 24 期（约 11 个月）统计。**默认停用**，需要时在实体列表启用 |
| `<油品>` 偏离均价 | % | 当前价相对 24 期均价的偏离，正数=偏贵。**默认停用** |
| 92/95 价差 | 元/L | 95 号减 92 号；两种油品都发布时才有 |
| 本期调价方向 | - | 上调 / 下调 / 搁浅；属性 `changes` 为各油品涨跌额 |
| 调价期号 | - | 接口的调价窗口期号（如 146），可用于判断数据是否更新 |
| 油价更新时间 | 时间戳 | 本期油价的生效时间；属性 `price_history` 为完整历史调价周期 |
| 调价周期结束日 | 日期 | 当前周期截止日，属性含 `days_left` 剩余天数 |
| 下次调价生效日 | 日期 | 周期结束日的次日 0 时，可直接做日历/提醒 |
| 距下次调价天数 | 天 | 适合做"调价前加满"的自动化 |
| 接口服务器时间 | 时间戳 | 中石化返回数据的服务器时间，用于判断数据新鲜度 |
| 油价位置 | - | 省份/价区；属性含 `area_desc`（官方适用州市说明）、`fuels`（已发布油品清单）、`source` |

### 车辆实体（每辆车一组）

| 实体 | 单位 | 说明 |
| --- | --- | --- |
| 当前里程表 | km | 最近一次加油的里程表读数；无记录时回退到配置的初始里程 |
| 累计行驶里程 | km | 最新里程 − 初始里程（未设初始里程时为加油区间里程和） |
| 累计加油量 | L | 所有记录加油量之和 |
| 累计加油费用 | 元 | 所有记录**挂牌价**之和（属性含 `total_payment`/`total_discount`/`avg_discount_rate`） |
| 累计实际支付 | 元 | 所有记录**真实付款**之和（旧记录无实付字段时按加油费用计） |
| 累计优惠 | 元 | Σ（加油费用 − 实际支付）；属性含 `avg_discount_rate` 优惠率、`last_discount` 最近一次优惠 |
| 最近油耗 | L/100km | 最近一次加油区间的油耗 |
| 平均油耗 | L/100km | 记录期总加油量（首箱不计）/ 记录期总里程 × 100 |
| 平均油价 | 元/L | 累计加油费用 ÷ 累计加油量（按挂牌价，口径与 1.0.4 一致） |
| 每公里油费 | 元/km | 累计加油费用 ÷ 累计行驶里程 |
| 加油次数 | 次 | 记录条数 |
| 最近加油日期 | 时间戳 | 最后一次加油时间 |
| 最近加油 | - | 摘要（日期 · 量 · 费用 · 实付 · 优惠 · 单价）；属性 `records` 为全部记录（含序号/实付/优惠/区间里程/区间油耗，序号与 delete/edit 服务一致），`stats` 为该车全部统计值 |
| 数据质量 | - | "正常" / "部分缺口（N 处）" / "需修正（N 项）"；属性 `problems` 列出时间-里程矛盾项，`odometer_gaps` 为缺少里程读数的区间数（见上文油耗计算规则） |

### 加油填表实体（单台「加油填表」设备）

| 实体 | 说明 |
| --- | --- |
| 车辆 | 下拉选择（多车时必选；只有一辆车时自动选中） |
| 里程表读数 | 里程（切换车辆时自动带出该车当前读数） |
| 加油量 | 升 |
| 加油费用 | 元，挂牌价合计 |

## 数据来源与接口

数据抓取自中国石化公开的"今日油价"页面：

| 接口 | 用途 |
| --- | --- |
| `GET /yjkqiantai/core/initCpb` | 建立会话 |
| `POST /yjkqiantai/data/switchProvince` | 切换省份（会话级） |
| `GET /yjkqiantai/data/initMainData` | 当日油价（省级 + 价区 area 列表） |
| `GET /yjkqiantai/data/initOilPrice` | 历史调价周期（约 24 期 ≈ 11 个月） |

接口为非官方公开接口，若中石化调整网站导致失效，欢迎提 Issue。
